# 日志测试

本目录执行 `make test`,或在项目根目录执行 `make log-test`.单独 `make` 只编译,默认生成 `logTest`,`make clean` 清理该程序.可以用 `BIN_DIR` 指定输出目录.

8 个场景覆盖默认关闭、INFO 阈值、同步与容量为 2 的异步日志、文件初始化失败与重试、队列关闭排空、并发写入、8 KiB 长记录和 50000 行轮转.测试自动创建并清理临时目录,子进程正常退出后检查日志文件,确保析构排空行为受到验证.每个场景有超时限制,失败返回非零.

测试不依赖数据库、网络端口或本机日志目录.没有注入线程创建失败,也不覆盖服务器连接与工作线程的全局退出协调.
